## What we did

### Homeowner range totals: `_min`/`_max` columns

The materials figure is a single number but labour is a range, so a homeowner's grand total
is a range as well. The maintainer chose to store both ends: `quotes.labour_total_min` /
`_max` and `grand_total_min` / `_max`. Contractor quotes write min = max. The midpoint
option was rejected because a reopened quote would have to rebuild the range, and v1 stores
estimates rather than rebuilding them. Build notes (validator rule for both ends, what
happens to the old single columns) are in `tasks/ai-material-estimation.md` §7.
