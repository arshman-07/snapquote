## Decisions made

| Decision | Reason |
|---|---|
| Store both `jobTypeId` + `jobType` on the draft | User wanted the stable id locked in now; but `jobType` is used as display text on 5 screens (overlines, `buildMaterialPackages`, `briefPlaceholder`), so keeping the name avoids threading a name-lookup everywhere. Id is ready for a future `quotes.job_type` relation / Phase-3 room-keyed config. |
| Offline falls back to static list (not a blocking error) | Field tool — starting a quote must never be blocked by an unreachable backend. |
| Fetch only `id, name, sort` | Only fields the step needs; `status` isn't exposed by the Public read policy anyway. |
